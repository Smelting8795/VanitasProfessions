# VanitasProfessions

Made by Tyska for Vanitas Guild EU WoW Forever PvP.

Shares guild members' professions and skill levels, and lets you search for a
specific craftable item to see who in the guild can make it.

## Features

- Shows every guildmate's professions and skill levels (addon-to-addon).
- Item search: type an item name and see who can craft it.
- Member search: type a name and see that person's professions.
- Hover a crafted item in the results for its recipe tooltip (reagents).
- Fully automatic sync on login; nothing to maintain by hand.

## Usage

- `/vp` opens and closes the window.
- Three filter boxes at the top: guild member, profession, item (cycle with Tab).
- `/vp request` forces a fresh sync from the guild.
- `/vp mine` lists how many recipes are cached per profession.

## Setup

Install the addon, then open each profession window once (and Enchanting) so your
recipes are learned and shared. This is only needed once; the cache survives
relogs. Every member who wants to appear must have the addon installed.
